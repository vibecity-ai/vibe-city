Four report-only browser testers, each on a private `npm run demo` server (FakeHermes, scripted chat), driven by
headless Chromium 156 (playwright-core) at 1440x900, 1280x720, 1024x768, 820x1180 and 390x844. Base: `parallel-work`

## High: the demo path a judge clicks breaks

1. **Hiring intake dead-ends in the demo.** Answer the ringing phone → every reply is "Ready when you are, boss.", no
   chips, no brief; shortlist/interview/hire unreachable. `scripts/demo-server.ts:55` matches
   `'Head of Agent Resources'`, but the intake prompt (`domain/hiringService.ts:286`) now says
   "You are <name>, Chief of Staff…". The `'Executive assistant'` branch (`demo-server.ts:39`) is dead too.
   Same file: the scripted brief is always "Support … credits a day" (shown as $5.00) whatever floor rang.
2. **Chief of Staff setup fails silently in the demo.** The prefilled model `deepseek-ai/DeepSeek-V4.1-Flash-1017`
   is not in FakeHermes' list (`testing/fakeHermes.ts:16`) → provisioning `state: error` ("model … is not available"),
   the card shows no error, and the chat says "I have no desk in Hermes yet, boss: start Hermes". In the real app too,
   any CoS sync failure is reported as "start Hermes" (`town/ui/NewDept.tsx:83`) instead of the real reason.
3. **Chief of Staff board missing in the demo → "Out of date" + "Reconnecting" on every load.** The demo only
   `addBoard`s listed floors; the CoS is unlisted, so `GET /api/departments/<cos>/quests` is 502
   (`board vc-… does not exist`) and its live socket keeps dropping. Fix: `kanban.addBoard(boardSlugForDepartment(chiefOfStaffId))`
   after the CoS provision in `demo-server.ts:116`.
4. **Reply chips that mean "yes" are sent as chat text and destroy the proposal.** Agent chat "Ship it"
   (`town/ui/Dialogue.tsx` `onSend` ~L224; cards only render for the last message ~L263) and the CoS "Looks good"
   chip (`NewDept.tsx:71-80`): no quest / no floor is created, and the card disappears for good. Only the small
   card button works. Same family: hiring "Not now" chip doesn't end the call (`Hiring.tsx:153`).
5. **Phone (390px): the page scrolls sideways.** Header overflows (scrollWidth 499: `.topkey.ops`, `.stale`,
   `.health`); finishing the tour leaves `scrollX=109` (left side of the console cut off, black strip right), and
   opening the Ops board lands at `scrollX=23, scrollY=523`. `Tour.tsx` never restores scroll.
